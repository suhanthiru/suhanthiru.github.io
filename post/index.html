Make a posting key on GitHub

  1. Open New fine-grained token on GitHub.
  2. Name it site posting and pick an expiration.
  3. Repository access: Only select repositories, then suhanthiru.github.io.
  4. Permissions: Issues → Read and write. Leave everything else at No access.
  5. Generate it, copy it, and paste it below.

This key can only open issues. It can't change any file on your site, so older content stays safe even if the key leaks. It's saved in this browser only.
