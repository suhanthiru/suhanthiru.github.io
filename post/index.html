Make a publishing key on GitHub

  1. Open New fine-grained token.
  2. Name it site publishing and pick an expiration.
  3. Repository access: Only select repositories, then suhanthiru.github.io.
  4. Permissions: Issues → Read and write. Leave everything else at No access.
  5. Generate it, copy it, and paste it below.

The key can only open issues and comments. A workflow on GitHub turns them into changes to your content files and is not allowed to touch the site's code. The key is saved in this browser only.
